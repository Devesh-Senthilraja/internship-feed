About the match score: keyword overlap between the posting and a fixed skill list (embedded C++, firmware, CAN, Linux, robotics, ROS2, OpenCV…). Most community listings only have a title, so treat it as a sorting aid, not a prediction. Postings pulled straight from company boards also use the description.

Filters: location is the only structured field. Class standing, grad window and export-control flags are keyword guesses on free text, so always confirm on the company page.

Sources: SimplifyJobs and vanshb03 Summer 2027 trackers, plus company boards (Greenhouse and Workday). Company pages win when they disagree with aggregators.

Where these postings come from

Each run pulls every source below, keeps Summer 2027 postings and merges duplicates. A tile's “via” line names the sources that listed it. Indeed and Glassdoor are not scraped.
